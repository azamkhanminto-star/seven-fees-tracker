# SEVEN brand assets

Vector logos extracted from `SEVEN_Logo_White_and_Teal.pdf` (supplied by the institute), cropped, with transparent backgrounds unless noted.

| File | Use on |
|---|---|
| `seven-logo.svg` | White or light backgrounds (dark lettering, full-colour tick and bars) |
| `seven-logo-light.svg` | Dark backgrounds such as navy or teal (white lettering, pastel tick and bars) |
| `seven-logo-teal.svg` | Stand-alone tile with the teal background included |

## Colours found in the logo

| Role | Hex |
|---|---|
| Lettering (dark) | `#0E0F12` |
| Teal background | `#0F766E` |
| Bar 1, yellow | `#FFC72C` |
| Bar 2, red | `#FF5A4E` (light variant `#FF8A80`) |
| Bar 3 / tick, green | `#22B573` (light variant `#7FE0B4`) |
| Bar 4 / tick, blue | `#3D8BFF` (light variant `#8EC2FF`) |

The brief also names Yellow `#FBB605` and Navy `#052A61`. The final report theme is a single setting and is still to be confirmed.
